# 3ds Max 2026 Professional Course RU

Автономный профессиональный курс для перехода с 3ds Max 2022 на 3ds Max 2026 и дальнейшего развития до уверенного production-уровня.

## Состав

- 17 модулей
- 57 занятий
- 5 финальных проектов
- версия-переход 2022 → 2026, сверенная с официальной документацией Autodesk
- 30 практических ускорений workflow «медленно → профессионально»
- мини-экзамены, последовательные подсказки и решения
- 8 профессиональных чеклистов
- приложение по горячим клавишам
- интерактивное отслеживание прогресса
- экспорт/импорт прогресса JSON
- автономная Word-версия

## Архитектура сайта

Сайт — статическое одностраничное приложение без обязательного backend. Учебная база встроена в проект; прогресс хранится в браузере. Для переноса между устройствами предусмотрен экспорт и импорт JSON. Это позволяет использовать курс без серверной базы и без зависимости от стороннего аккаунта.
